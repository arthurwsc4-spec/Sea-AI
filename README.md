# Sea-AI
This project was developed as a school assignment to demonstrate the fundamentals of rule-based artificial intelligence. It uses simple logical rules and decision-making processes to simulate how an AI can solve problems without machine learning.

The main goal of the project is to illustrate how predefined conditions, logical operators, and structured rules can be combined to create intelligent behavior in a clear and easy-to-understand way. It serves as an introduction to AI concepts and highlights the difference between traditional rule-based systems and modern learning-based approaches.
